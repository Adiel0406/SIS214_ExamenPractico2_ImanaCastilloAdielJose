# Recursos del portafolio

Esta carpeta reúne los medios locales usados por `../index.html`. Las referencias se escriben como rutas relativas a la raíz del sitio para que funcionen en GitHub Pages.

## Carpetas

- `images/`: fotografía de perfil (`foto.jpg`) e imagen de proyecto (`proyecto.jpg`).
- `audio/`: presentación profesional (`presentacion.mp3`).
- `video/`: demostración de proyecto (`proyecto.mp4`).
- `documents/`: espacio disponible para documentos que decidas publicar.

## Mantenimiento

Al añadir o reemplazar un recurso, actualiza el `src` o `srcset` correspondiente y comprueba que el nombre, la extensión y las mayúsculas coincidan. Añade texto alternativo descriptivo a las imágenes informativas. Publica únicamente recursos que tengas autorización para compartir y evita incluir datos personales sensibles.
